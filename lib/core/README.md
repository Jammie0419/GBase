## 计划功能

### state_store.py - 统一状态存储
- 全局状态管理
- 状态持久化
- 状态变更追踪
- 状态快照和恢复

## 设计目标

### 统一状态管理
- 替代分散在各模块中的状态管理代码
- 提供一致的状态访问 API
- 支持状态的版本控制和回滚

### 持久化支持
- 状态自动保存到磁盘
- 支持多种存储后端（JSON、SQLite、内存）
- 跨会话状态恢复

### 变更追踪
- 记录状态变更历史
- 支持状态差异比较
- 状态变更通知机制

## 与其他功能域的交互（计划）

- 被 `kernel` 调用：全局状态管理
- 被 `memory/` 调用：记忆状态持久化
- 被 `evolution/` 调用：进化状态追踪
- 被 `scheduler/` 调用：任务状态管理

## 当前替代方案

目前各模块使用自己的状态管理方式：
- `storage.py` 提供数据库存储
- 各引擎维护自己的内部状态
- 会话状态通过 `session.py` 管理
